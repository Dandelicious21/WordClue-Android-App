# WordClue Android

Word Clue game for DAN and NORLYN.

## Build APK on GitHub

1. Open the **Actions** tab.
2. Select **Build WordClue APK**.
3. Click **Run workflow**.
4. After the workflow finishes, open the workflow run.
5. Under **Artifacts**, download **WordClue-APK**.
6. Extract the downloaded artifact to get `app-debug.apk`.

The workflow uses Gradle 8.7, JDK 17, and Android SDK 35. No Gradle Wrapper is required.
